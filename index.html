Local Inbox 개인정보처리방침

시행일: 2026년 10월 14일

Local Inbox(이하 "앱")는 사용자가 선택한 메신저 앱의 알림을 사용자 기기 안에만 보관하는 앱입니다. 이 방침은 앱이 어떤 정보를 다루고, 어디에 보관하며, 사용자가 어떻게 관리할 수 있는지 설명합니다.

1. 개발자가 수집하는 정보

개발자는 사용자의 개인정보를 수집하지 않습니다. 앱에는 계정, 로그인, 서버, 광고, 분석, 추적 기능이 없고 인터넷 권한도 없습니다. 앱이 저장한 정보는 개발자나 제3자에게 전송되지 않습니다.

2. 기기 안에서 처리하는 정보

  • 알림 정보: 사용자가 동의하고 저장을 켠 앱(카카오톡, Microsoft Teams, Instagram, Telegram)의 알림에 표시된 앱 이름, 대화방 이름, 보낸 사람 이름, 메시지 텍스트, 수신 시각, 1:1·그룹 구분, 작은 알림 아이콘 이미지.
  • 설정 정보: 앱별 저장 여부, 동의 버전, 보관기간, 알림 접근 연결 상태와 마지막 수신 시각.

사진, 동영상, 첨부 파일, 링크의 내용은 저장하지 않습니다. 저장을 켜지 않은 앱의 알림, 통화 중이나 업로드 진행처럼 계속 표시되는 알림은 저장하지 않습니다.

3. 알림 접근 권한

앱은 Android의 '알림 접근' 권한을 사용합니다. Android는 이 권한을 받은 앱에 기기의 모든 알림을 전달하지만, 앱은 사용자가 저장을 켠 앱의 알림만 저장하고 나머지는 저장하지 않습니다. 사용자는 Android 설정에서 언제든 권한을 해제할 수 있습니다.

4. 보관 위치와 기간

정보는 앱 내부 저장소에만 보관되며, Android 클라우드 백업과 기기 간 이전 대상에서 제외됩니다. 기본값은 자동 삭제 안 함이며, 사용자는 데이터 관리 화면에서 7일, 30일, 90일 보관기간을 고를 수 있습니다.

5. 내보내기

사용자가 직접 내보내기를 실행하면 선택한 앱의 기록을 텍스트나 JSON 파일로 사용자가 고른 위치에 저장합니다. 그 위치가 클라우드와 동기화되는 경우 해당 서비스의 정책이 적용되며, 앱에서 기록을 삭제해도 내보낸 파일은 삭제되지 않습니다.

6. 삭제

사용자는 데이터 관리 화면에서 앱별로 기록을 삭제할 수 있습니다. 앱을 삭제하거나 Android 설정에서 앱 데이터를 지우면 저장된 모든 기록이 삭제됩니다. 개발자는 사용자 데이터를 보관하지 않으므로 별도의 삭제 요청 절차가 없습니다.

7. 아동

앱은 13세 미만 아동을 대상으로 하지 않습니다.

8. 방침 변경

방침이 바뀌면 이 페이지에 변경 내용과 시행일을 게시합니다. 광고처럼 정보 처리 방식이 달라지는 기능을 추가할 때는 기능을 배포하기 전에 이 방침을 먼저 고칩니다.
